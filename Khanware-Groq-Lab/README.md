# Khanware Groq Lab

Môi trường mô phỏng độc lập, chỉ dành cho kiểm thử giao diện, chọn đáp án tự động trên câu hỏi giả lập, tiến độ cục bộ và Groq API. Không thay đổi hoặc tích hợp với trang đánh giá của bên thứ ba.

## Chạy
Mở `index.html` trên trình duyệt hoặc triển khai bằng GitHub Pages. Chọn Cài đặt để nhập Groq API key tạm thời, rồi chọn AI Groq để phân tích câu hỏi. Key chỉ giữ trong bộ nhớ của trang, không lưu trong source hoặc localStorage.

## Giới hạn
Không phải bản sao 100% Khanware gốc. CORS có thể chặn Groq khi gọi trực tiếp từ trình duyệt. Chưa kiểm thử với API key thực.
